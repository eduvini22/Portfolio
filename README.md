# Portfólio Pessoal

Este projeto foi criado como atividade prática da trilha GitHub Foundations.

## Objetivo

Criar um portfólio simples utilizando HTML e CSS e aplicar conceitos de Git e GitHub, como commits, branches e Pull Requests.

## Tecnologias

- HTML
- CSS

## Sobre o projeto

O site apresenta informações sobre o estudante, habilidades, projetos e formas de contato.
